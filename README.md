## 📖 About

This repository tracks my hands-on learning path toward becoming a **Java Full-Stack Developer**, covering everything from Core Java fundamentals to building production-style projects with **Spring Boot, Spring Security, Microservices, Docker, Kafka, and React**.

Each folder in this repo corresponds to a topic — with notes, practice code, and mini-projects built while learning.

## ⚙️ How to Run Projects Locally

```bash
# Clone the repository
git clone https://github.com/<your-username>/java-fullstack-journey.git

# Navigate to a specific project folder
cd java-fullstack-journey/10-spring-boot

# Run with Maven
mvn spring-boot:run
```
