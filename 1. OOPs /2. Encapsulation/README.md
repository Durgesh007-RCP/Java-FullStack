| **#** | **Program**        | **Concept Used**                           |

| 1     | `School.java`      | Private Fields, Getters & Setters          |
| 2     | `Office.java`      | Encapsulation with Employee Data           |
| 3     | `BankAccount.java` | Data Hiding, Getters, Setters & Validation |
| 4     | `ATM.java`         | PIN & Balance Encapsulation                |
| 5     | `atn.java`         | Encapsulation with ATM Operations          |

## 🧠 Concepts Covered

## 🎯 Goal

To understand how **Encapsulation protects object data** by keeping variables private and providing controlled access through public methods.

> **Hide Data → Control Access → Validate Data → Protect Object** 🔐
